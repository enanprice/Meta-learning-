:::warning Mark it honestly
**M** marks are for method and survive an arithmetic slip. **A** marks are for accuracy and are
**dependent** on the corresponding M mark — no method written down, no accuracy mark. **B** marks
stand alone.

If you didn't write it, you don't get it. See *Exam Skills → Command Words and How Marks Are Awarded*.
:::

## Question 7 — 9 marks

| Part | Scheme | Marks |
|---|---|---|
| (a) | Uses $\sin^2 x = 1 - \cos^2 x$ | M1 |
| | $3 - 3\cos^2 x = 4 - 4\cos x$ | A1 |
| | Rearranges to $3\cos^2 x - 4\cos x + 1 = 0$ **(answer given)** | A1* |
| (b) | Factorises: $(3\cos x - 1)(\cos x - 1) = 0$ | M1 |
| | $\cos x = \dfrac13$ or $\cos x = 1$ | A1 |
| | $x = 70.5°$ | A1 |
| | $x = 289.5°$ | A1 |
| | $x = 0°$ | A1 |
| | $x = 360°$ | A1 |

**Notes.** (a) This is a "show that", so every line must be present; the final A is withheld for a
jump straight to the printed answer. (b) $289.5°$ must come from $360 - 70.5$. Losing the endpoints
$0°$ and $360°$ is the most common error — the interval is closed. Deduct one A mark for each
extra solution given in range.

## Question 11 — 10 marks

| Part | Scheme | Marks |
|---|---|---|
| (a) | Uses volume: $x^2 h = 500$ so $h = \dfrac{500}{x^2}$ | M1 |
| | Correct surface area for an **open** box: $A = x^2 + 4xh$ | M1 |
| | Substitutes for $h$ | M1 |
| | $A = x^2 + \dfrac{2000}{x}$ **(answer given)** | A1* |
| (b) | $\dfrac{dA}{dx} = 2x - \dfrac{2000}{x^2}$ | M1 |
| | Sets $= 0$ and solves: $x^3 = 1000$ | M1 |
| | $x = 10$ | A1 |
| | $\dfrac{d^2A}{dx^2} = 2 + \dfrac{4000}{x^3}$ | M1 |
| | States this is positive at $x = 10$ (value 6), hence a **minimum** | A1 |
| | $A_{\min} = 300\text{ cm}^2$ | A1 |

**Notes.** (a) $A = x^2 + 4xh$ — using $2x^2 + 4xh$ (a closed box) scores M0 for that mark and cannot
reach the printed answer. (b) The justification mark requires the second derivative to be evaluated
or its sign argued, not merely written down.

## Question 12 — 10 marks

| Part | Scheme | Marks |
|---|---|---|
| (a) | Defines two consecutive odd numbers as $2n+1$ and $2n+3$, $n$ an integer | B1 |
| | Expands: $(2n+1)^2 + (2n+3)^2 = 4n^2+4n+1+4n^2+12n+9$ | M1 |
| | $= 8n^2 + 16n + 10$ | A1 |
| | $= 2\left(4n^2 + 8n + 5\right)$, so the sum is even | A1 |
| | States $4n^2 + 8n + 5$ is **odd**, so the sum is $2 \times$ odd and therefore not divisible by 4 | A1 |
| (b) | Evaluates $f(-3) = -54 + 9 + 39 + 6 = 0$ | M1 |
| | Concludes $(x+3)$ is a factor by the factor theorem | A1 |
| | Obtains the quadratic factor $2x^2 - 5x + 2$ | M1 |
| | Factorises it: $(2x-1)(x-2)$ | M1 |
| | $f(x) = (x+3)(2x-1)(x-2)$ | A1 |

**Notes.** (a) The final A is the crux and is frequently missed: showing the sum is even is not
enough, you must show the other factor is odd. (b) The conclusion "so $(x+3)$ is a factor" must be
stated, not implied.

## Question 13 — 11 marks

| Part | Scheme | Marks |
|---|---|---|
| (a) | $A = 300$ | B1 |
| | Substitutes: $1200 = 300e^{5k}$ | M1 |
| | $e^{5k} = 4$ so $5k = \ln 4$ | M1 |
| | $k = \dfrac{\ln 4}{5} = 0.2773\ldots = 0.277$ (3 s.f.) **(answer given)** | A1* |
| (b) | $N = 300e^{12k}$ | M1 |
| | $N = 8360$ (3 s.f.) | A1 |
| (c) | $\dfrac{10000}{300} = e^{kt}$ | M1 |
| | $t = \dfrac{\ln(100/3)}{k}$ | M1 |
| | $t = 12.65$ hours (2 d.p.) | A1 |
| (d) | Identifies a specific limitation, e.g. unlimited exponential growth is unrealistic — food, space or nutrients will eventually constrain the population | B1 |
| | Relates it to the model in context, e.g. so the model will overestimate $N$ for large $t$ | B1 |

**Notes.** (a) Working must reach $k$ exactly before the given 3 s.f. value; quoting $0.277$ without
derivation scores M0 A0. (b) Use the exact $k$, not the rounded 0.277 — the rounded value gives 8330,
which is outside the accepted range. This is a premature-rounding trap. (d) "It might not be accurate"
scores B0: name the mechanism.
