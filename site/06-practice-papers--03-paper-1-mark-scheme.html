Mark it honestly

M marks are for method and survive an arithmetic slip. A marks are for accuracy and are dependent on the corresponding M mark — no method written down, no accuracy mark. B marks stand alone.

If you didn't write it, you don't get it. See Exam Skills → Command Words and How Marks Are Awarded.

Question 1 — 4 marks#

PartSchemeMarks
(a)$\sqrt{50} = 5\sqrt2$ or $\sqrt{18} = 3\sqrt2$M1
$8\sqrt2$A1
(b)Multiplies numerator and denominator by $(\sqrt5 + 1)$M1
$\dfrac{6\sqrt5 + 6}{4} = \dfrac{3\sqrt5 + 3}{2}$A1

Notes. (b) Accept $a = 3$, $b = 3$, $c = 2$, or the unsimplified $\frac{6\sqrt5+6}{4}$ only if followed by the simplified form. Denominator must be shown as $5 - 1 = 4$.

Question 2 — 5 marks#

PartSchemeMarks
(a)Takes 2 out of the first two terms: $2(x^2 - 6x) + 23$M1
$2\left[(x-3)^2 - 9\right] + 23$M1
$2(x-3)^2 + 5$A1
(b)Minimum value $= 5$B1
occurring at $x = 3$B1

Notes. (a) The second M is for completing the square inside the bracket. A common error is $2(x-3)^2 - 9 + 23$; this scores M1 M0 A0.

Question 3 — 6 marks#

PartSchemeMarks
(a)Correct structure with at least two correct binomial coefficients, e.g. $1 + 8(3x) + 28(3x)^2 + \dots$M1
$1 + 24x$A1
$+\,252x^2$A1
$+\,1512x^3$A1
(b)States or uses $x = 0.01$M1
$1.2667$A1

Notes. (a) Powers must be applied to the whole of $3x$: $28 \times 3x^2 = 84x^2$ scores A0. (b) $1 + 0.24 + 0.0252 + 0.001512 = 1.266712 \to 1.2667$. Award A1 only for the 4 d.p. answer.

Question 4 — 7 marks#

PartSchemeMarks
(a)Attempts to complete the square in both $x$ and $y$: $(x-4)^2 - 16 + (y+2)^2 - 4 - 5 = 0$M1
Centre $(4, -2)$A1
Radius $5$A1
(b)$(8-4)^2 + (1+2)^2 = 16 + 9 = 25$, so $P$ lies on $C$B1
(c)Gradient of radius $= \dfrac{1-(-2)}{8-4} = \dfrac34$, so gradient of tangent $= -\dfrac43$M1
$y - 1 = -\dfrac43(x - 8)$M1
$4x + 3y - 35 = 0$A1

Notes. (a) Radius given as 25 scores A0 — the equation gives $r^2$. (c) The first M requires the negative reciprocal; using $\frac34$ for the tangent scores M0.

Question 5 — 8 marks#

PartSchemeMarks
(a)$3x^2 - 12x$ (at least two terms correct)M1
$\dfrac{dy}{dx} = 3x^2 - 12x + 9$A1
(b)Sets $\dfrac{dy}{dx} = 0$ and solves: $3(x-1)(x-3) = 0$M1
$(1, 6)$A1
$(3, 2)$A1
(c)$\dfrac{d^2y}{dx^2} = 6x - 12$M1
At $x=1$, $\dfrac{d^2y}{dx^2} = -6 < 0$ so maximumA1
At $x=3$, $\dfrac{d^2y}{dx^2} = 6 > 0$ so minimumA1

Notes. (b) $y$-coordinates must come from the original equation. (c) A correct sign-change argument using values of $\frac{dy}{dx}$ either side scores equally, provided the values are shown.

Question 6 — 6 marks#

PartSchemeMarks
(a)Recognises the quadratic in $3^x$, e.g. sets $u = 3^x$M1
$(u-1)(u-9) = 0$ so $u = 1$ or $u = 9$A1
$x = 0$A1
$x = 2$A1
(b)Combines the logs: $\log_2\left[x(x+3)\right] = 2$ and writes $x(x+3) = 4$M1
$x = 1$ only (rejecting $x = -4$)A1

Notes. (a) Both values of $u$ must be converted back. (b) The A mark requires $x = -4$ to be rejected, or for only $x=1$ to be stated as the answer; a reason ("log of a negative is undefined") is expected but not required here.

Question 7 — 9 marks#

PartSchemeMarks
(a)Uses $\sin^2 x = 1 - \cos^2 x$M1
$3 - 3\cos^2 x = 4 - 4\cos x$A1
Rearranges to $3\cos^2 x - 4\cos x + 1 = 0$ (answer given)A1*
(b)Factorises: $(3\cos x - 1)(\cos x - 1) = 0$M1
$\cos x = \dfrac13$ or $\cos x = 1$A1
$x = 70.5°$A1
$x = 289.5°$A1
$x = 0°$A1
$x = 360°$A1

Notes. (a) This is a "show that", so every line must be present; the final A is withheld for a jump straight to the printed answer. (b) $289.5°$ must come from $360 - 70.5$. Losing the endpoints $0°$ and $360°$ is the most common error — the interval is closed. Deduct one A mark for each extra solution given in range.

Question 8 — 8 marks#

PartSchemeMarks
(a)Sets the equations equal and rearranges: $x^2 - 3x + 2 = 0$M1
$x = 1$ and $x = 2$A1
$(1, 3)$ and $(2, 4)$A1
(b)Forms (line $-$ curve): $\displaystyle\int_1^2 \left(-x^2 + 3x - 2\right)dx$M1
Integrates: $-\dfrac{x^3}{3} + \dfrac{3x^2}{2} - 2x$M1
Substitutes both limits and subtractsM1
$-\dfrac23 - \left(-\dfrac56\right)$A1
Area $= \dfrac16$A1

Notes. (b) Curve $-$ line gives $-\frac16$; award full marks only if the modulus is taken or the subtraction is set up the right way round. Answer must be exact — $0.167$ scores A0.

Question 9 — 7 marks#

PartSchemeMarks
(a)$a + 4d = 17$M1
$a + 11d = 45$M1
$d = 4$A1
$a = 1$A1
(b)$S_{20} = \dfrac{20}{2}\left[2(1) + 19(4)\right]$M1
$= 10 \times 78$M1
$= 780$A1

Notes. (a) Both M marks are for correct use of $u_n = a + (n-1)d$; using $a + 5d$ for the 5th term scores M0. (b) Accept the alternative $S_n = \frac n2(a + l)$ with $l = u_{20} = 77$.

PartSchemeMarks
(a)V-shape with vertex on the $x$-axisM1
Vertex at $\left(\dfrac52, 0\right)$A1

(b)$2x - 5 = x + 1$ or $-(2x-5) = x+1$M1

Question 11 — 10 marks#

PartSchemeMarks
(a)Uses volume: $x^2 h = 500$ so $h = \dfrac{500}{x^2}$M1
Correct surface area for an open box: $A = x^2 + 4xh$M1
Substitutes for $h$M1
$A = x^2 + \dfrac{2000}{x}$ (answer given)A1*
(b)$\dfrac{dA}{dx} = 2x - \dfrac{2000}{x^2}$M1
Sets $= 0$ and solves: $x^3 = 1000$M1
$x = 10$A1
$\dfrac{d^2A}{dx^2} = 2 + \dfrac{4000}{x^3}$M1
States this is positive at $x = 10$ (value 6), hence a minimumA1
$A_{\min} = 300\text{ cm}^2$A1

Notes. (a) $A = x^2 + 4xh$ — using $2x^2 + 4xh$ (a closed box) scores M0 for that mark and cannot reach the printed answer. (b) The justification mark requires the second derivative to be evaluated or its sign argued, not merely written down.

Question 12 — 10 marks#

PartSchemeMarks
(a)Defines two consecutive odd numbers as $2n+1$ and $2n+3$, $n$ an integerB1
Expands: $(2n+1)^2 + (2n+3)^2 = 4n^2+4n+1+4n^2+12n+9$M1
$= 8n^2 + 16n + 10$A1
$= 2\left(4n^2 + 8n + 5\right)$, so the sum is evenA1
States $4n^2 + 8n + 5$ is odd, so the sum is $2 \times$ odd and therefore not divisible by 4A1
(b)Evaluates $f(-3) = -54 + 9 + 39 + 6 = 0$M1
Concludes $(x+3)$ is a factor by the factor theoremA1
Obtains the quadratic factor $2x^2 - 5x + 2$M1
Factorises it: $(2x-1)(x-2)$M1
$f(x) = (x+3)(2x-1)(x-2)$A1

Notes. (a) The final A is the crux and is frequently missed: showing the sum is even is not enough, you must show the other factor is odd. (b) The conclusion "so $(x+3)$ is a factor" must be stated, not implied.

Question 13 — 11 marks#

PartSchemeMarks
(a)$A = 300$B1
Substitutes: $1200 = 300e^{5k}$M1
$e^{5k} = 4$ so $5k = \ln 4$M1
$k = \dfrac{\ln 4}{5} = 0.2773\ldots = 0.277$ (3 s.f.) (answer given)A1*
(b)$N = 300e^{12k}$M1
$N = 8360$ (3 s.f.)A1
(c)$\dfrac{10000}{300} = e^{kt}$M1
$t = \dfrac{\ln(100/3)}{k}$M1
$t = 12.65$ hours (2 d.p.)A1
(d)Identifies a specific limitation, e.g. unlimited exponential growth is unrealistic — food, space or nutrients will eventually constrain the populationB1
Relates it to the model in context, e.g. so the model will overestimate $N$ for large $t$B1

Notes. (a) Working must reach $k$ exactly before the given 3 s.f. value; quoting $0.277$ without derivation scores M0 A0. (b) Use the exact $k$, not the rounded 0.277 — the rounded value gives 8330, which is outside the accepted range. This is a premature-rounding trap. (d) "It might not be accurate" scores B0: name the mechanism.
